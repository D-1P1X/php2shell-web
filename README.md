# PHP2Shell

Školní projekt do předmětu o komunikaci s AI: vícestránkový web shrnující kritické
zranitelnosti v jádru PHP z října 2026, přezdívané **PHP2Shell**
(`CVE-2026-109618`, `CVE-2026-109619`).

## Stránky

- `index.html` — úvod a shrnutí obou CVE
- `zranitelnost.html` — technický popis a časová osa
- `ochrana.html` — doporučené kroky zmírnění rizika
- `zdroje.html` — citované zdroje a použití AI

## Design

Jednotný vzhled v `style.css`: zelený terminálový „hackerský“ styl (monospace
font JetBrains Mono, zelená na černém, SVG ilustrace serverů a časové osy).

## Zveřejnění

Web běží přes GitHub Pages z větve `main`, složka `/` (root).

## AI

Při tvorbě obsahu a kódu pomohl Claude (Anthropic). Detaily a prompty jsou
na stránce [Zdroje a AI](zdroje.html).
